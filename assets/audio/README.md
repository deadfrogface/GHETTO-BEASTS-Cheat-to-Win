# Audio placeholders

Drop optional files here (OGG/WAV). `AudioBus` falls back to procedural blips if missing.

Preferred free sources (see root `OPEN_SOURCE.md`): **Kenney** (CC0), **Freesound** (CC0/CC-BY — keep attribution).

Suggested filenames:

- `hit.ogg`, `summon.ogg`, `raid_siren.ogg`, `ui_click.ogg`, `pack_open.ogg`, `whoosh.ogg`
- `bgm_district.ogg` (optional loop — Music bus / crossfade)

Buses: **Master** → **Music**, **SFX** (created at runtime by `AudioBus`).
